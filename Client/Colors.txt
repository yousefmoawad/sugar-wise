## 🎨 Special Gradients
- **Hero Primary:** `from-[#2DA1D7] to-[#8EC641]` (Light)
- **Hero Dark:** `from-[#1a5f7f] to-[#4d6a23]` (Dark)
- **Accent Health:** `from-[#8EC641] to-[#2DA1D7]`
- **Gamer Accent:** `from-orange-500 to-yellow-500`

---

## ℹ️ Configuration Note
The dark mode is triggered using the `class` strategy in `tailwind.config.js`.
Transitions are globally applied with `transition-colors duration-300`.

## 📐 Typography and font size (Updated)
| Element | Tailwind Classes | Usage |
| :--- | :--- | :--- |
| **Hero Main Title** | `text-4xl md:text-6xl lg:text-7xl` | Main impact headline on Home page |
| **Section Headings** | `text-4xl md:text-5xl` | Primary headers for sections |
| **Feature Card Titles** | `text-3xl` | Titles inside informational cards |
| **Primary Subtitles** | `text-xl md:text-2xl` | Descriptions under section headings |
| **Body Text (Upscaled)** | `text-lg` | Main body copy within cards for better legibility |
| **Mobile Labels** | `text-base font-bold` | Navigation items and interactive labels on mobile |

## 🌌 Page-Level Backgrounds
- **Light Gradient:** `bg-gradient-to-br from-white via-[#2DA1D7]/5 to-[#8EC641]/5`
- **Dark Gradient:** `bg-gradient-to-br from-gray-950 via-[#1a5f7f]/10 to-[#4d6a23]/10`
- **Glassmorphism:** `bg-white/80 dark:bg-gray-900/80 backdrop-blur-md` (Used in Navbar)
